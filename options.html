Blocked sites

Type a prefix. Everything that starts with it gets blocked.

    Nothing is blocked yet. Add a prefix like example.com/1.

    How a prefix works

    example.com/1 blocks every page that starts with example.com/1, on http and https. Subdomains of the domain are blocked too, so example.com also covers blog.example.com.

    Rules are kept as *://example.com/1. Write https://example.com if you only want the https version.

    Your list syncs with Chrome. Chrome asks for access to a site the first time you add it, because an extension can only block a site it is allowed to touch.
